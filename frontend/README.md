# KALAKRITI

## India's Living Craft Heritage

KALAKRITI is a premium digital marketplace for Indian handicrafts, artisans and living craft traditions.

## Stack

### Frontend
- Next.js 14
- TypeScript
- Tailwind CSS
- Zustand
- Axios
- Zod

### Backend
- FastAPI
- SQLAlchemy 2
- Alembic
- PostgreSQL

### Infrastructure
- Redis
- Celery
- Docker
- Nginx

## Important

The backend database remains authoritative.

Do not introduce Prisma.

Do not duplicate backend models inside the frontend.
